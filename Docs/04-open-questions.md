# 04 问答台账

规则以问答方式逐条确定。每答完一条写入结论，并同步回填 `02-combat-rules.md`、
`03-ui-and-interaction.md` 或 `07-domain-model.md`。

状态：`待答` / `已答`

## 一、已确定

按编号排序，与提出顺序无关。

| 编号 | 问题 | 结论 |
| --- | --- | --- |
| Q1 | 卡牌的背面是什么？ | **背面是另一套独立效果（双面卡）**：用正面后翻成背面留在手牌，再用则触发背面效果并翻回正面 |
| Q2 | 弃牌堆收什么？ | **回合结束时手牌全部进入弃牌堆**，下回合重新抽 |
| Q3 | 敌人翻面后血量如何？ | **第二形态满血重开**，第二形态归零才真正死亡 |
| Q4 | 「类似杀戮尖塔」包含什么？ | 含地图的最小循环。其中「暂不做战后奖励」已被 Q31 覆盖 |
| Q5 | 能量 / 抽牌 / 手牌上限？ | **先用占位值**：3 能量 / 抽 5 / 上限 10 |
| Q6 | 玩家生存规则？ | **生命 + 护甲，尖塔式**：护甲每回合开始清零，生命归零失败 |
| Q7 | 敌人行动是否明示？ | **完全明示**，显示下回合行动与数值 |
| Q8 | 同回合能否反复使用同一张卡？ | **可以无限次**，只受能量限制 |
| Q9 | 翻转动画形式？ | **3D 绕轴翻转** |
| Q10 | 拖拽容错？ | **高亮合法目标 + 拖到空白或非法处松手回弹** |
| Q11 | 战斗结束卡牌状态？ | **全部恢复正面**，不跨战斗漂移 |
| Q12 | 敌人攻击力如何生效？ | **每回合固定造成该数值伤害**，无行动池 |
| Q13 | 哪些卡需要目标？ | **只有攻击类**，其余点击即用 |
| Q14 | 形态切换是否可配置？ | **翻面是通用行为**；敌人即「角色卡」（带攻击力与生命的卡牌），血量归零只是触发翻面的一种原因 |
| Q15 | 同时有几个敌人？ | **多敌人同时在场**，全部消灭才胜利 |
| Q16 | 翻面状态何时重置？ | **战斗内跟随卡牌**，跨弃牌堆与重新抽牌都不变 |
| Q17 | 两面是否共用费用与类型？ | **完全独立**，各有费用、类型、效果 |
| Q18 | 第二形态血量上限？ | **两形态各自配置，可不同** |
| Q19 | 地图做到什么程度？ | 分支节点图。实际形态由 Q24 确定为「每战后选下一关」 |
| Q20 | 玩家状态显示在哪？ | **手牌区上方** |
| Q21 | 两形态攻击力是否独立？ | **各自独立配置** |
| Q22 | 敌人何时翻面？ | **血量归零当场立即翻面**，满血进入第二形态 |
| Q23 | 地图规模？ | **主线 3–4 场战斗 + Boss**，节点类型含战斗与休整 |
| Q24 | 地图有没有分支？ | **每场战斗后从 2–3 个候选中选下一关**；左上角显示当前层数 / 总层数 |
| Q25 | 多敌人伤害结算顺序 | 待答 |
| Q26 | 翻转动画的时长与音效 | **约 0.35 秒 + 翻转音效** |
| Q27 | 关卡候选的类型清单 | **普通战斗、精英战斗、休整、商店**（不做事件节点） |
| Q28 | 首版卡牌数量？ | **约 10 张**（20 个面） |
| Q29 | 战斗失败后流程 | **本局结束，从头开始** |
| Q30 | 玩家也是角色卡吗？ | **不是**，玩家目前只有血条，没有卡牌，也不参与翻面 |
| Q31 | 战后做不做奖励？ | **要做**，覆盖 Q4 中「暂不做战后奖励」的表述 |
| Q32 | 「下一关」候选代表什么？ | **混合**：有的候选是不同敌人组合，有的候选是休整 |
| Q33 | 是否支持其他翻面触发？ | **做通用翻面接口，并做一张验证用卡** |
| Q34 | 玩家有没有护甲？ | **保留护甲**，每回合开始清零。Q30 的「只有血条」指玩家不是卡牌，不是取消护甲 |
| Q35 | 战后奖励给什么？ | **金币 + 卡牌三选一** |
| Q36 | 休整节点做什么？ | **二选一：回复生命 / 移除一张卡** |
| Q37 | 金币花在哪？ | **新增商店节点**，金币用于买卡牌与移除服务 |
