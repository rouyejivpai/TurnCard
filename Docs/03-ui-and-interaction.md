# 03 界面与交互

状态：仅记录需求直接给出的部分。未定义的表现细节见 `04-open-questions.md`。

## 1. 战场分区

四个固定区域，位置由需求直接指定（R6）：

```
┌──────────────────────────────────────────┐
│                                          │
│                敌人（正前方）              │
│                                          │
│                                          │
│  抽牌堆                          弃牌堆    │
│  （左下）                        （右下）  │
│                                          │
│              手牌区（正下方）              │
└──────────────────────────────────────────┘
```

- 敌人位于画面正前方，是视觉焦点，也是拖拽的目标区域。
- 一场战斗中可以同时存在多个敌人（Q15），因此正前方区域需要容纳多张敌人卡并排，
  横向排布方式与最大数量待定（→ Q22、Q23）。
- 手牌区在正下方，卡牌横向排列。
- 抽牌堆固定左下、弃牌堆固定右下，两处都显示剩余数量（数量显示方式待定）。
- 画面左上角显示**当前层数 / 本阶段总层数**（Q24）。
- **玩家状态区（生命值与护甲）放在手牌区上方**（Q20）——需求原本没有这块位置，
  是 Q6 确认玩家有生命与护甲后补充的。

## 2. 卡牌

- 每张卡有正面与背面两种表现（R1），两面各是一套独立的效果、费用与类型（Q17）。
- **卡面随当前朝上的一面整体切换**：费用数字、类型标识、描述文本都属于「面」，
  翻面时一起换掉，而不是在同一张卡面上叠加两套信息。
- 使用后翻面（R3），翻面过程必须有动画（R10）。
- 玩家需要能一眼看出「这张卡现在朝上的哪一面」，否则无法决策（因为两面效果不同）。

## 3. 敌人卡

敌人沿用卡牌载体，但版面与普通卡不同（R7、R8）：

| 位置 | 内容 |
| --- | --- |
| 左下角 | 攻击力 |
| 右下角 | 血量 |

- 敌人同样有正反两面，代表两种形态（R9）。
- 形态切换默认发生在血量归零时（R9）。
- **敌人的下一步行动完全明示给玩家**（Q7）：敌人卡上需要有位置展示下回合要做什么、
  以及具体数值。该区域的位置与样式待定（敌人卡左下已是攻击力、右下是血量）。
- **翻面是即刻反馈**：敌人血量归零的瞬间就翻面并满血进入第二形态（Q22），
  翻转动画在战斗中途播放，不能等下一个回合。
- 敌人翻面与卡牌翻转使用同一套动画形式（Q9）。

## 4. 交互

| 卡牌类型 | 操作 | 反馈 |
| --- | --- | --- |
| 攻击类（唯一需要目标的类型，Q13） | 拖拽到敌人身上释放 | **卡牌停在原位、只向上浮起**；从卡牌上边缘拉出一条贝塞尔曲线箭头指向指针（R4、R5） |
| 其余所有卡 | 单击 | 立即使用并翻转 |

拖拽时的关键约定：

- 卡牌**不跟随鼠标**。跟手会让箭头起点和终点重合，等于没有箭头；停在原位既保住了
  手牌位置的可预期性，也让箭头有明确的起点与长度。
- 箭头是二次贝塞尔曲线，不是直线；终点带箭头头部。
- **弧线始终向上凸起**：控制点沿弦的中垂线偏移，并强制取朝上的一侧。
  如果直接用固定的左手法线，指针换到另一侧时弧线会翻到下方，观感是错的。
- 指针悬停在敌人上时，敌人卡轻微放大作为可投放提示。
- 松手时若指针不在敌人身上，卡牌回到原位，不消耗能量。

### 查看信息

| 操作 | 结果 |
| --- | --- |
| 右键单击一张手牌 | 在该牌的**右上方**弹出信息面板，显示它翻面后的名字、费用、类型、效果 |
| 悬停在一张手牌上 0.8 秒 | 同上 |
| 移开指针 | 悬停触发的面板收起；右键触发的保持显示，直到点击别处或出牌 |
| 点击抽牌堆 / 弃牌堆 | 打开牌堆面板，以**真实卡面**陈列其中的卡牌 |

面板出现时带一个放大回弹的动画（0.18 秒，easeOutBack），位置会被限制在屏幕内，
避免靠近边缘的卡牌把面板顶出画面。

抽牌堆列表会打乱显示顺序，避免泄露下一回合的抽牌顺序；弃牌堆按进入顺序显示。

多敌人时，拖拽箭头需要能明确指向被选中的那个敌人（高亮方式待定，→ Q10）。

见 Q10。

## 5. 翻转动画

需求明确要求翻转动画必须存在（R10），它是核心体验而非点缀。

- **形式已定：3D 绕轴翻转**（Q9）——卡牌绕纵轴旋转，翻到背面时露出另一面。
- **节奏已定：约 0.35 秒，配一声翻转音效**（Q26）。
- 实现上需要注意：UGUI 没有背面剔除，转到 90° 之后必须切换显示的面，
  否则会看到镜像的反面。

仍待定：翻面过程中是否同时露出两面、是否伴随位移或缩放。

## 6. 战斗之间的界面

每场战斗结束后进入「选择下一关」界面（Q24）：

- 给出 2–3 个候选，玩家选一个进入。
- 候选以卡片形式呈现，每张卡片说明该关卡的类型与风险。
- 左上角的层数显示在这两个界面之间保持一致，让玩家知道自己推进到哪一步。

候选具体代表什么尚未确定（→ Q32）。
