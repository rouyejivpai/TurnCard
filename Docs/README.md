## 书写约定

- 文档使用 Markdown，文件名用英文短横线，正文用中文。
- 一份文档只讲一件事，避免单文件过长。
- 规则类内容必须能落到实现：判定条件写成确定的分支，数值标【默认】并注明可调。
- 未决定的内容一律标注编号（如 Q1），不写「大概」「可能」之类的模糊描述。
