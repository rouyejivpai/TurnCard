# 23 手牌布局与悬停表现

## 1. 手牌布局：增量同步 + 补间

**旧实现的问题**：`BuildHand()` 每次都是「全部销毁 → 全部重建 → 全部从抽牌堆飞入」。
所以手牌数量一变，屏幕上看到的是整排牌重新飞一遍，而不是现有牌让位。

**现在的做法**（`BattleForm.BuildHand`）：

1. **移除**：手牌里已经不存在的牌，解除事件并销毁视图；
2. **补建**：按手牌顺序找已有视图，缺的才 `CardView.Create`（只有新牌播发牌动画）；
3. **重排**：`ApplyHandLayout` 统一算位置，老牌走 `CardView.TweenHome()`，
   新牌走 `PlayDeal()`。

位置公式（与原实现一致，只是改成过渡）：

```
spacing = min(卡宽 + 间隙, max(卡宽×0.55, (可用宽度 - 卡宽) / (张数 - 1)))
startX  = -(张数 - 1) × spacing / 2
第 i 张  →  (round(startX + i × spacing), 0)
```

过渡参数：0.2s、`OutCubic`、每张错峰 `i × 15ms`（整排不会一起弹）。
补间用独立的 `layout` id，不会和悬停 / 抬起 / 翻面互相打断。

**触发时机**：`CardDrawn` 与 `CardDiscarded` 都会把 `m_HandDirty` 置脏，
`LateUpdate` 帧末统一重排一次（逐事件重建会反复销毁视图、打断 tween）。

> 之前弃牌**不置脏**，所以弃掉一张后其余牌原地不动、中间留空洞——这是「手牌数变更后布局没变」的主因。

## 2. 悬停：投影 + 浮动

### 2.1 投影（shader）

- 着色器：`Shaders/UICardShadow.shader`（`TurnCard/UICardShadow`）
- 材质：`Resources/UI/Card/CardShadow.mat`
- 做法：把卡框贴图的 **alpha 当剪影**，染成半透明黑，UV 偏移 + 9 点取样柔化，
  画在卡牌**第一个子节点**（也就是最底层）。

```csharp
// 影子相对卡牌偏移，右下方向
ShadowOffset = (14, -18)
```

因为剪影来自卡框贴图，**换卡框时影子会自动跟着变**，不需要单独出影子图。

### 2.2 浮动

- 悬停先抬 `FloatLift = 20px`，再按**随机方向**做小幅度往返：
  角度 `-35°~35°`，幅度 `2.5~4.5px`，周期 `1.5s`，`InOutSine` + `Yoyo` 循环。
- 幅度上限刻意压低，避免"漂浮跑偏"。
- 退出时 `KillFloat()` + 0.16s 回位。

**坑**：`DOTween.Kill(rect, "float")` 杀不掉 Sequence 内部循环的子 tween，
会导致浮动一直跑、牌被顶高 20px 不回位。必须**持有 Sequence 引用再 Kill**。

## 3. 可调参数一览

全部集中在 **`Resources/Config/HandLayoutSettings.asset`**（菜单 `Create/TurnCard/Data/Hand Layout Settings`）。

| 分组 | 参数 | 默认 | 说明 |
| --- | --- | --- | --- |
| 布局 | `layoutDuration` | 0.20s | 手牌增删后剩余牌滑到新位置的时长 |
| | `layoutStagger` | 0.015s | 每张之间的错峰 |
| | `minSpacingRatio` | 0.55 | 手牌挤压时的最小间距（占卡宽） |
| 悬停 | `hoverScale` | 1.25 | 悬停放大倍数 |
| | `liftHeight` | 20px | 悬停抬起高度 |
| | `floatAmplitudeMin/Max` | 2.5 / 4.5px | 浮动幅度范围 |
| | `floatAngleRange` | 35° | 浮动方向随机范围 |
| | `floatPeriod` | 1.5s | 浮动一个来回 |
| | `returnDuration` | 0.16s | 退出悬停回位 |
| 投影 | `shadowOffset` | (14, -18) | 相对卡牌的偏移 |
| | `shadowOpacity` | 0.42 | 最浓时的透明度（材质 `_Color.a` 固定为 1） |
| | `shadowFade` | 0.15s | 淡入淡出 |

## 4. 表现类配置统一放在 `Resources/Config/`

| 资产 | 管什么 |
| --- | --- |
| `Config/BattleFxSettings.asset` | 投射物飞行、多段伤害节奏、翻面时长 |
| `Config/HandLayoutSettings.asset` | 手牌布局、悬停浮动、投影 |
| `Config/EnemyDeathSettings.asset` | 敌人死亡刀痕动画 |
| `Config/IntentIconSet.asset` | 意图图标（枚举 → Sprite） |

新增表现参数时**优先往这四张里加字段**，不要再散落到 `Resources` 根目录或具体界面目录下。
