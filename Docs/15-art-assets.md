# 美术资源需求清单

## 已确认的整体规格

| 项 | 决定 |
| --- | --- |
| 画风 | 像素风，参考《吸血鬼幸存者》，**鲜亮复古**配色 |
| 卡牌尺寸 | **380×536**（高清像素基准，等比对应游戏内 190×268） |
| 卡牌模板 | **正反共用同一套**，结构仿杀戮尖塔（简洁清晰） |
| 卡牌插画 | **暂不做** |
| 角色美术 | **人工绘制**，标准 **48×64**；敌人目前只是测试占位，后续可能部分交给 AI |
| 背景 | 像素场景（战斗 / 地图 / 主菜单） |
| 出图方式 | GPT 生图 → **纯色键色底** → 抠图 → 缩放到目标像素尺寸 |

游戏基准分辨率 1920×1080。所有像素图放大时用**最近邻（Point）**，不允许插值模糊。

## 七、交付约定

- UI 元素 PNG + 透明；背景可用 PNG/JPG
- **纯色键色底**（如品红 #FF00FF）出图，方便抠图
- 像素图缩放到目标尺寸时用最近邻，不插值
- 命名：`类型_用途_状态`，如 `btn_normal.png`、`card_frame.png`、`icon_energy.png`
