# 30 · 弹道来源（特效从哪张牌出发）

## 问题

以前伤害只记「打到谁、多少、是出牌还是瞬发」，**没记是哪张牌打的**。
表现层于是统一用「被出的那张牌」当起点，导致：

- 条件反射翻出邻牌的瞬发 → 炮弹从**条件反射**飞出去；
- 暗藏杀意使用邻牌背面的伤害 → 也从暗藏杀意飞出去；
- 炮击特效（`IsCannon`）同理按被出牌的面判断，类型也可能错。

## 结构

```
CardEffects 执行时 → BattleState.m_ExecutingCard（当前效果来源卡）
                        ↓ DealDamage 入队时带上
                  PendingHit { Enemy, Amount, Origin, Source }
                        ↓ 表现层逐发消费
       BattleForm.PlayDamageQueue → TryGetHitOrigin(hit.Source) → 起点
```

## 关键点

| 项 | 说明 |
| --- | --- |
| 执行上下文 | `BattleState.EnterCardContext(card)` / `ExitCardContext(prev)`，出牌、瞬发、邻牌效果三处都会切换 |
| 入队 | `PendingHit.Source = m_ExecutingCard` |
| 起点解析 | `TryGetHitOrigin()`：手牌里还在 → 用它的视图位置；已离场 → 用**离场前的位置快照**；都没有 → 面板中心 |
| 位置快照 | `RememberCardPosition()` 在弃牌动画、回合结束散牌前记录，存在表现层的 `m_CardLastWorldPos` |
| 特效类型 | `IsCannon(sourceFace, amount)` 只看**来源卡当前面**是否「随机/全体」或伤害 ≥ 8 |

逐发解析很重要：同一批 `PendingHits` 里可能混着多张来源（比如条件反射翻出的瞬发 + 自身伤害），
所以起点必须在循环**内**算，不能在循环外算一次。

## 实测

| 场景 | 结果 |
| --- | --- |
| 条件反射翻出速射火炮 → 火炮瞬发 3 点 | `PendingHit.Source` = 火炮，`Origin = Instant` ✅ |
| 暗藏杀意使用邻牌背面（18 点） | `Source` = 邻牌「搭箭」，不是暗藏杀意 ✅ |
| 实机出速射火炮（装填 → 翻面 → 瞬发 3 点） | 敌人 18 → 15，队列正常清空 ✅ |
