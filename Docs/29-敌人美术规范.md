# 29 · 敌人美术规范与接入流程

## 1. 设计基准

- 设计网格 **48 × 64**（与敌人卡框同网格，见 `21-敌人卡面.md`）。
- 工程里保存的 PNG 统一是 **96 × 128（2× 导出）**，显示时靠 UI 拉伸到卡面窗口（168 × 232），
  所以必须 **Point 过滤 + 不压缩**，否则像素会被插值糊掉。

## 2. 目录与命名

一只敌人一个目录，目录名用英文（与 `Enemies.xlsx` 的 `frontArt/backArt` 对应）：

```
Assets/Game/Art/Cards/<Name>/
├─ <Name>_1.png        正面立绘（96×128）
├─ <Name>_2.png        反面立绘（96×128）
├─ <Name>_1_sheet.png  正面 idle 序列帧（8 帧横排，768×128）
└─ <Name>_2_sheet.png  反面 idle 序列帧（8 帧横排，768×128）
```

序列帧按 96px 一帧从左到右切；没有序列帧的敌人只保留 `_1/_2` 静态图。

## 3. 美术给的原始文件 → 目标文件

美术给的是 1× 素材（48×64）和 Aseprite 源文件：

| 原始 | 含义 | 目标 |
| --- | --- | --- |
| `01.png` | 正面静态帧 | `<Name>_1.png`（2× 放大） |
| `02.png` | 反面静态帧 | `<Name>_2.png`（2× 放大） |
| `dt_01.png` | 正面 8 帧序列（384×64） | `<Name>_1_sheet.png`（2× 放大 → 768×128） |
| `dt_02.png` | 反面 8 帧序列 | `<Name>_2_sheet.png` |
| `*.aseprite` | 源文件 | 留在 `Assets/Game/Art/123`，不参与导入 |

**2× 放大会破坏画质吗？** 不会：用最近邻（NEAREST）放大，每个像素变成 2×2 同色方块，
形状、颜色、像素边界完全不变，只是和现有 96×128 素材对齐了像素密度。

**只有序列帧、没有静态帧怎么办？** 从序列帧裁第 1 帧（96×128）作为静态图。

## 4. 导入设置（必须）

| 项 | 值 |
| --- | --- |
| Texture Type | Sprite (2D and UI) |
| Sprite Mode | Single |
| Filter Mode | **Point (no filter)** |
| Compression | **None** |
| Alpha Is Transparency | 开 |
| Mip Maps | 关 |
| Max Size | 2048 |
| Pixels Per Unit | 100 |

## 5. 数据接入

1. 图片放到 `Cards/<Name>/`；
2. `DataTables/Enemies.xlsx` 的 `frontArt` / `backArt` 填路径（`Assets/Game/Art/Cards/<Name>/<Name>_1.png`）；
3. `Tools/TurnCard/生成数据表`（或编辑器里 `DataTableImporter.GenerateAll()`）重生成资产；
4. 打开战斗确认：立绘非空、占位色块关闭、翻面后换图。
