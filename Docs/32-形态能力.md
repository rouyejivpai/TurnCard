# 32 · 形态能力（面绑定被动）

## 规则

**一个形态的被动能力只在那一面朝上时生效。** 翻面 = 换一套能力，而不是把能力带到另一面去。

| 例子 | 正面（农夫） | 反面（狼人） |
| --- | --- | --- |
| 能力 | 开幕·虚弱、开幕·壁垒 | 嗜血·再生（受伤后获得 2 层自愈） |
| 翻到农夫 | ✅ 生效 | ❌ 不生效 |
| 翻到狼人 | ❌ 不生效 | ✅ 生效 |

普通 buff（玩家打的虚弱、易伤、力量……）**不属于任何一面**，翻面时保留。

## 敌人：数据与实现

数据仍在 `Enemies.xlsx` 的 `frontBuffs / backBuffs`：

- `trigger = battleStart` 的条目 → **一次性开幕效果**，执行完即弃（不常驻、不显示、不被双生共享）；
- 其他条目 → **形态能力**，常驻在敌人身上，但打上 `BuffInstance.FormBound` 标记。

翻面流程（`BattleState.OnEnemyFlipped`）：

```
enemy.Buffs.RemoveFormBound()   // 只摘掉旧面的能力，普通 buff 留着
ApplyFormBuffs(enemy)           // 挂上新面的能力（含一次性开幕效果）
RunTriggers(BattleStart)        // 新面自己的开幕触发
```

### 能力衍生出来的 buff 也算形态能力

例如「开幕·壁垒」的效果是 `buff_self:5`（给自己挂壁垒）、「嗜血·再生」的效果是
`buff_self:25,2`（给自己挂 2 层自愈）——这些**由能力产生**的 buff 同样归属那一面，
翻面时要一起消失。

实现上用作用域：`BattleState.m_FormBoundDepth`，在执行形态能力的效果期间加一，
期间 `ApplyBuff` 创建的所有 buff 自动带 `FormBound`。

## 玩家：能力牌（Power）

**没有能力区**。规则是：

> 能力牌**正面朝上、还在手牌里**时，它的被动持续生效；翻到背面、打出或离开手牌即失效。

实现（`BattleState.RefreshPowerCards()`）：

```
生效集合 = { 手牌中 Side == Front 且 Face.Type == Power 的牌 }
失效的牌  → 移除它产生过的 buff（按引用逐个摘）
新生效的牌 → 执行一次它这一面的效果，并记录这次产生的 buff
```

调用时机：回合开始抽完牌、出牌结算后、任意牌翻面时、弃牌时。

- 能力牌产生的 buff 记录在 `m_PowerBuffs[card]`，所以「翻到背面」不会误删别的来源的同类 buff；
- 翻回正面会重新执行一次该面效果（重新获得力量等）；
- 能力牌自己也会翻面（`黑/白`、`条件反射` 等），所以这个机制天然跟着翻面走。

实测（测试牌 id 17「战术素养」，正面 `buff:2,1,-1,player`）：

| 操作 | 玩家力量 |
| --- | --- |
| 起手抽到、正面朝上 | +1 ✅ |
| 翻到背面 | 移除 ✅ |
| 翻回正面 | +1 ✅ |
