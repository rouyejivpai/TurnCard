## 2. 关卡推进

由 Q24 确定：

- 每场战斗结束后，进入「选择下一关」界面，给出 **2–3 个候选**让玩家选一个。
- 关卡总数为主线上 3–4 场战斗 + 一个 Boss（Q23）。
- 界面左上角显示**当前层数 / 本阶段总层数**。

## 5. 由已确定规则推出的结论

1. **牌库在一场战斗内是有状态的**：每张卡记录当前朝上的面（Q16），战斗结束复位（Q11）。
2. **一副牌实际等于两副牌**：两面独立（Q17）。
3. **能量是唯一的限流阀**：卡牌可无限复用（Q8）。
4. **强面与弱面必须成对设计**。
5. **敌人是角色卡的实例**（Q14），所以敌人与卡牌共用「面」与「翻面」的底层机制，
   只是多带了攻击力与生命两项数据。
6. **翻面是通用操作**（Q14）：血量归零只是「触发翻面」的一种原因，不存在独立的
   「形态切换」逻辑。
7. **敌人翻面是即时反馈**（Q22）：伤害结算当场翻转，动画会在战斗中途播放。
8. **拖拽只用于攻击牌**（Q13）。
9. **本版内容量很小**：3–4 场战斗 + Boss（Q23）。
