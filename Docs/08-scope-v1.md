# 08 本版范围

规则已通过问答闭合，本篇把「要做成什么样」收敛成一份清单，作为实现与验收的依据。

## 1. 一局的完整流程

```
开局（固定卡组）
  ↓
选关：2–3 个候选，选一个
  ↓
进入节点 ── 普通战斗 / 精英战斗 / 休整 / 商店
  ↓
战斗胜利 → 奖励：金币 + 卡牌三选一
  ↓
回到选关 …… 重复 3–4 次，最后一场为 Boss
  ↓
击败 Boss = 通关；战斗失败 = 本局结束，从头开始
```

## 2. 内容清单

| 项 | 数量 / 说明 |
| --- | --- |
| 卡牌 | 约 10 张，每张两面，共 20 个面 |
| 敌人 | 待编写；含普通、精英、Boss 三档 |
| 关卡 | 主线 3–4 场战斗 + 1 场 Boss |
| 节点类型 | 普通战斗、精英战斗、休整、商店 |
| 不做 | 事件节点 |

## 3. 核心循环（战斗）

- 回合制，玩家回合 → 敌人回合。
- 手牌 5 张、能量 3 点、护甲每回合清零（占位值）。
- 打出一张牌 → 触发当前面效果 → 卡牌翻面并留在手牌。
- 同一张牌可反复使用，只受能量限制。
- 回合结束：手牌全部进弃牌堆，下回合重新抽。
- 战斗结束：所有卡牌恢复正面。

## 4. 敌人

- 敌人是「角色卡」：带攻击力与生命，有正反两面。
- 每回合按当前形态的攻击力造成固定伤害，意图完全明示。
- 当前形态血量归零 → 当场翻面，第二形态满血开始。
- 第二形态归零才死亡。两形态的血量与攻击力各自配置。

## 5. 奖励与经济

- 战后奖励：金币 + 卡牌三选一（可以不给卡）。
- 休整：二选一，回复生命 或 移除一张卡。
- 商店：用金币买卡牌、买移除服务。
- 金币只来自战斗奖励，只花在商店。
