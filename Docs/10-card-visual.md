## 2. CardView 的复用关系

同一个卡面预制体被四处复用，缩放不同：

| 使用方 | 缩放 | 实际尺寸 | 额外叠加 |
| --- | --- | --- | --- |
| 手牌 | 1.0 | 190 × 268 | — |
| 牌堆陈列 | 1.32 | 250 × 352 | — |
| 敌人卡 | 1.5 | 285 × 402 | 意图（上方）、攻击力（左下）、血量（右下） |
| 背面预览 | 1.5 | 285 × 402 | 顶部「翻面后 · 背面」标签 |

这就是「所有卡牌统一」的结构保证：改一次卡面，四处同时生效。
敌人卡的特殊信息是叠在卡面上的浮层，不另做一套卡面。

## 4. 字体

预制体**不带字体**：中文字体是运行时从系统字体动态创建的，不是资产，存进预制体会变成空引用。
运行时各视图会给缺字体的文本补上系统字体。

想让预制体在设计期就显示中文：导入一个 TTF 到工程，在预制体里给对应 Text 指定该字体即可，
运行时不会覆盖已有设置。

## 5. 改卡面时注意

- 卡牌**背景色**由代码按类型设置（攻击红 / 技能蓝 / 能力紫），预制体上的底板颜色只是占位；
  要换成美术底板，需要同时去掉 `CardView.ShowFace` 里的颜色赋值。
- `CardView` 上绑定了 6 个引用（Background、Art、CostBadge、CostText、NameText、TypeText、
  DescriptionText）。重命名或删除节点会导致引用断开，需要重新拖一次。
- 翻转动画通过旋转根节点、并在 90° 后反转子节点来避免镜像，因此**子节点必须是平铺结构**，
  不要再套一层会旋转的容器。
- 敌人卡与背面预览都是「只显示不绑定卡牌实例」的模式（`CardView.CreateDisplay`），
  它们不会触发背面查看，也不参与拖拽。

## 6. 可打出描边（shader）

**旧做法**：`UIEdgeGlow` 按「UV 到矩形边缘的距离」算光圈，所以永远是**圆角矩形**，
跟卡框的真实轮廓无关——卡框换成有缺口的形状时会明显穿帮。已删除。

**现在的做法**：`TurnCard/UICardOutline`（`Shaders/UICardOutline.shader`），
**直接替换 `Background` 的材质**，在卡框贴图自带的透明边距里画描边。

```
d = 到轮廓的距离（6 档探测）        t = d / 描边宽度   （0 = 贴边，1 = 最外）
颜色 = lerp(深色, 浅色, t)          透明度 = (1-t) × lerp(1, 外沿alpha, t)
波   = 一个 t 从 0 扫到 1 的窄带    随相位外扩并淡出
最终颜色 = 卡面 × 自身 alpha + 描边色 × ring，按 alpha 合成
```

要点：

| 项 | 说明 |
| --- | --- |
| 为什么能画在 Background 上 | 卡框贴图自带透明边距（`cardframeWood` 左 8 / 上 4 / 右 10 / 下 10 贴图像素，显示时 6~15px），描边就落在这圈边距里 |
| 形状来源 | 就是 `Background` 自己的 `_MainTex`，不需要 `_ShapeTex`；换皮肤描边自动跟着变 |
| **距离要分档** | 只按一个半径采样会漏掉落在两档之间的像素，描边会出现断裂。现在沿 1/6~6/6 倍宽度分 6 档探测（每档 8 方向） |
| 内深外浅 | `_Color`（深）→ `_PaleColor`（浅），同时透明度从 1 降到 `_OuterAlpha` |
| 外扩波 | 用同一个 `t`，波就是一个从 0 扫到 1 的窄带，**天然不会超出描边宽度**，因此也不会被贴图边距裁掉 |
| 开关方式 | `SetPlayable(true/false)` 把两面 `Background.material` 在描边材质 / 默认材质之间切换 |
| **厚度上限** | 描边宽度必须 **≤ 贴图边距**。`cardframeWood` 最窄处（上边）只有 4 贴图像素 ≈ 6 显示像素，默认取 5px |
| 材质 | `Resources/UI/Card/CardOutline.mat`；**所有卡牌共用一个材质** |
| 参数 | `Resources/Config/CardVisualSettings.asset`：内外颜色 / 外沿alpha / 宽度 / 强度 / 柔化 / 波（颜色、强度、速度、带宽） |

实测（在真实 `cardframeWood` 的 alpha 上模拟，宽度 5px）：

| 距轮廓 | t | 描边 alpha |
| --- | --- | --- |
| 1px | 0.17 | 1.00 |
| 2px | 0.33 | 0.62 |
| 3px | 0.50 | 0.28 |
| 4px | 0.67 | 0.14 |
| 5px | 1.00 | 0.00 |

波会让中间几档的亮度随相位变化（同一像素在相位 0.2 时 1.00、在 0.8 时 0.69），看起来是一道从卡牌往里亮、向外淡出的波纹。
