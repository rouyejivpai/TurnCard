## 2. CardView 的复用关系

同一个卡面预制体被四处复用，缩放不同：

| 使用方 | 缩放 | 实际尺寸 | 额外叠加 |
| --- | --- | --- | --- |
| 手牌 | 1.0 | 190 × 268 | — |
| 牌堆陈列 | 1.32 | 250 × 352 | — |
| 敌人卡 | 1.5 | 285 × 402 | 意图（上方）、攻击力（左下）、血量（右下） |
| 背面预览 | 1.5 | 285 × 402 | 顶部「翻面后 · 背面」标签 |

这就是「所有卡牌统一」的结构保证：改一次卡面，四处同时生效。
敌人卡的特殊信息是叠在卡面上的浮层，不另做一套卡面。

## 3. CardView 层级

```
CardView            (Image 底板，兼作点击热区)
├─ CostBadge        (Image，费用角标)
│  └─ Cost          (Text)
├─ Name             (Text)
├─ Art              (Image，方形美术区，当前 96×96)
├─ Type             (Text)
└─ Description      (Text)
```

纵向分区（以 268 高的卡面为准）：

| 区域 | 纵向范围 | 内容 |
| --- | --- | --- |
| 0–48 | 顶部 | 费用角标（44×44，左）与名称（右） |
| 52–148 | 上中 | 美术区 96×96 |
| 151–173 | 中下 | 类型 |
| 174–254 | 底部 | 描述（约 3 行） |

## 4. 字体

预制体**不带字体**：中文字体是运行时从系统字体动态创建的，不是资产，存进预制体会变成空引用。
运行时各视图会给缺字体的文本补上系统字体。

想让预制体在设计期就显示中文：导入一个 TTF 到工程，在预制体里给对应 Text 指定该字体即可，
运行时不会覆盖已有设置。

## 5. 改卡面时注意

- 卡牌**背景色**由代码按类型设置（攻击红 / 技能蓝 / 能力紫），预制体上的底板颜色只是占位；
  要换成美术底板，需要同时去掉 `CardView.ShowFace` 里的颜色赋值。
- `CardView` 上绑定了 6 个引用（Background、Art、CostBadge、CostText、NameText、TypeText、
  DescriptionText）。重命名或删除节点会导致引用断开，需要重新拖一次。
- 翻转动画通过旋转根节点、并在 90° 后反转子节点来避免镜像，因此**子节点必须是平铺结构**，
  不要再套一层会旋转的容器。
- 敌人卡与背面预览都是「只显示不绑定卡牌实例」的模式（`CardView.CreateDisplay`），
  它们不会触发背面查看，也不参与拖拽。

## 6. 可打出描边（shader）

**旧做法**：`UIEdgeGlow` 按「UV 到矩形边缘的距离」算光圈，所以永远是**圆角矩形**，
跟卡框的真实轮廓无关——卡框换成有缺口的形状时会明显穿帮。已删除。

**现在的做法**：`TurnCard/UICardOutline`（`Shaders/UICardOutline.shader`），
把**卡框贴图的 alpha 当轮廓**，在轮廓外侧膨胀出一圈描边：

```
outline = dilate(alpha, r) − alpha      // r = 描边宽度（只画这一圈）
```

要点：

| 项 | 说明 |
| --- | --- |
| 形状来源 | `_ShapeTex` = 当前那一面的 `Background.sprite.texture`；换皮肤描边自动跟着变，不需要单独出描边图 |
| 光晕图尺寸 | 比卡牌大 `outlinePadding`（默认 10px），描边画在卡牌**外侧**，不会盖住卡面 |
| UV 映射 | 光晕图比卡牌大，`_Expand = (卡宽 + 2×padding) / 卡宽`，先把 uv 映射回卡牌本体再采样 |
| **厚度** | 采样半径**就是** `outlineWidth`，只画贴边的一圈，**不要再加更大半径的柔光**——否则会糊成一片、看起来离卡牌很远 |
| 柔化 | `_Softness` 只对描边做 gamma，不改变厚度 |
| 呼吸 | `_PulseAmount / _PulseSpeed` 让描边亮度轻微起伏 |
| 材质 | `Resources/UI/Card/CardOutline.mat`；因 UGUI 不支持 MaterialPropertyBlock，**按卡框贴图缓存材质实例**（材质数 = 皮肤数） |
| 参数 | `Resources/Config/CardVisualSettings.asset`：颜色 / 宽度 / 外扩 / 强度 / 呼吸 / 柔化（默认 5px / 10px / 1.0 / 0.3） |

> **注意**：`cardframeWood` 这张卡框本身在贴图里有 8~14 像素的透明边距（显示时 12~21px），
> 而且轮廓在竖直方向上略呈弧形。描边跟的是**这张图的不透明轮廓**，不是卡牌 RectTransform 的矩形边——
> 这是刻意的（否则又回到"永远画一个圆角矩形"的老问题）。

实测（在真实 `cardframeWood` 的 alpha 上模拟）：描边带宽 5px 时，
在 y=0.05/0.25/0.5/0.75/0.95 各行，描边都落在**轮廓外侧 0.8~7.2px** 内，紧贴边缘。
