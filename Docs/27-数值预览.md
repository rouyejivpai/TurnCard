# 27 · 数值预览（受 buff 影响的数值显示真实值）

## 规则

界面上的数值一律显示**实际会发生的值**；只要和卡面/招式的原始值不同，就用
`#FF5F5F` 标红，让玩家知道"这个数字被 buff 改过"。

覆盖范围（一期）：

| 位置 | 显示 |
| --- | --- |
| 手牌描述里的 `{damage}` / `{armor}` | 经玩家自身 buff（力量 `damage_dealt`、虚弱 ×0.75 等）结算后的值 |
| 拖牌指着某个敌人时 | 额外把该目标的 `damage_taken`（易伤）算进去，松手恢复 |
| 敌人意图的伤害数字 | 敌人攻击加成 + 玩家 `damage_taken` 结算后的值 |

## 数据写法

卡面描述里用占位符，不要写死数字：

| 写法 | 含义 |
| --- | --- |
| `{damage}` / `{dmg}` / `{demage}` | 这一面的伤害（后两个是历史拼写，等价） |
| `{armor}` | 这一面的护甲 |
| `{name}` / `{cost}` | 名称 / 费用 |
| 其他 token | 回落到 `CardFace.Params` 里的同名参数 |

> 如果描述里写死数字（如"造成 6 点伤害"），预览就没有可替换的位置，数值不会变。

## 计算

`BattleState` 提供四个纯函数，**和结算共用 `ApplyBuffModifiers`**，所以"显示值 = 实际值"：

```csharp
ValuePreview PreviewPlayerDamage(CardFace face, EnemyInstance target);  // 自身 damage_dealt + 目标 damage_taken
ValuePreview PreviewPlayerArmor (CardFace face);                        // armor_dealt（暂无 buff）
ValuePreview PreviewEnemyAttack(EnemyInstance enemy);                   // 敌人 damage_dealt + 玩家 damage_taken
ValuePreview PreviewEnemyArmor (EnemyInstance enemy);
```

`ValuePreview.Modified = Value != BaseValue`，界面据此决定是否标红。
预览**不消耗** buff 层数（`consume: false`）。

## 刷新时机

`BattleForm.RefreshAllPreviews()`，用「脏标记 + 帧末合并」，同一帧多次事件只刷一次：

| 触发 | 场景 |
| --- | --- |
| `PlayerBuffs.Changed` / 各 `enemy.Buffs.Changed` | 上/掉 buff |
| `PlayerHpChanged` / `PlayerArmorChanged` / `EnergyChanged` | 数值变化 |
| `TurnStarted` | 回合开始（虚弱减层、护甲清零） |
| `DamageApplied` | 伤害落地 |
| `CardDiscarded` | 弃牌后手牌变化 |
| 拖牌 hover 目标变化 | 目标易伤不同 |
| `BuildBattle` 结束 | 手牌/敌人卡刚建好 |

## 实测

挂「虚弱」（伤害 ×0.75）后：

| 卡 | 原值 | 显示 |
| --- | --- | --- |
| 攻击（id 1） | 3 | `<color>2</color>` |
| 闪电破击（id 15） | 4 | `<color>3</color>` |
| 协同攻击（id 10） | 4 | `<color>3</color>` |

再给敌人挂「易伤」（×2）并模拟悬停该目标：卡面变成 **6 / 5 / 6**（仍标红），松手回到 3 / 2 / 3。

敌人意图：哥布林攻击原值 3，玩家有易伤时显示 **6**（红色）。

## 二期待办

1. **参数类数值**：`damage_plus_instants:4,4` 里的"每瞬发 +4"目前显示固定值，需要给 effect 加预览钩子。
2. **`{demage}` 的"每张"语义**：协同攻击（id 10）显示的是**每张攻击牌的伤害**，不是总伤害；如需显示总量要改数据结构。
3. 关键词提示面板、牌组列表等复用同一套预览。
