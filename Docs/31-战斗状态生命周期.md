# 31 · 战斗状态生命周期

## 状态机在哪

```
ProcedureBoot → ProcedureMainMenu → ProcedureBattle ⇄ ProcedureReward / Rest / Shop / Map
                                        │
                                        └─ ProcedureBattle.OnLeave → UIHost.Close(BattleForm)
                                              └─ BattleForm.OnClose → ReleaseBattleState()
```

- 进战斗：`ProcedureBattle.OnEnter` 打开 `BattleForm`，`BattleForm.OnShow` → `StartBattle()`。
- 出战斗：`ProcedureBattle.OnLeave` **关闭界面**，关闭回调里做整场清理。
- 战斗内还有一个子状态：`BattleFinishedEvent` → 选关/奖励面板，仍属于同一场战斗。

## 两种状态，边界必须清楚

| 归属 | 存储 | 退出战斗时 |
| --- | --- | --- |
| **整局（run）** | `RunState`：Hp / MaxHp / Gold / Deck / Map / NodeIndex | **保留** |
| **单场战斗（battle）** | `BattleState`：手牌、抽/弃牌堆、敌人、buff、待结算队列、意图、选择态 | **全部清空** |
| **界面临时** | `BattleForm`：手牌视图、敌人视图、悬停目标、位置快照、协程、buff 图标条 | **全部清空** |
| **静态缓存** | `CardPreviewSource`、`BattleForm.DebugPendingLineup` / `PendingRouteSelect` | **置空** |

## 重置清单（`BattleState.Clear()`）

| 类别 | 内容 |
| --- | --- |
| 牌 | 手牌 / 抽牌堆 / 弃牌堆 |
| 敌人 | `m_Enemies`（含各自 buff、意图队列） |
| buff | `PlayerBuffs.Clear()` |
| 待结算 | `m_Pending`（伤害）、`m_PendingFlips`、`m_PendingInstants` |
| 结算上下文 | `m_DeferDamage` / `m_InstantPhase` / `m_InstantDepth` / `m_ExecutingCard` / `m_PlayTarget` / `m_FlipSource` / `m_LastInstantFlip` |
| 选择态 | `PendingChoice` / `SelectedForChoice` |
| 计数 | `m_PlaysThisTurn` / `InstantCountThisTurn` / `TurnNumber` |
| 回合标记 | `IsPlayerTurn` |
| **事件** | 全部置 null（`Changed`、`PlayerHpChanged`、`DamageApplied`…）——UI 的 lambda 也是订阅者，不清会一直吊着界面对象 |

## 重置清单（`BattleForm.ReleaseBattleState()`）

```
StopAllCoroutines()          // 关幕/翻面/出牌协程
m_HandViews / m_EnemyCardViews / m_CardLastWorldPos  清空
m_HoverTarget / m_ChoiceView / m_Busy / m_RenderDirty 归位
m_PlayerBuffStrip            销毁（否则每场战斗在 buff 区叠加一条）
m_Vm.Update(null, null)      丢掉 ViewModel 里持有的旧 CardInstance
CardPreviewSource.State/Target = null
DebugPendingLineup = null；PendingRouteSelect = false；m_PendingPool = null
m_State.Clear() → m_State = null
```

## 血量在「整局 ↔ 战斗」之间怎么走

| 方向 | 位置 |
| --- | --- |
| 进战斗 | `BattleForm.BuildBattle` → `m_State.BeginPlayerHp(RunState.Current.Hp)`（不再每场满血） |
| 出战斗 | `ProcedureBattle.OnBattleFinished` → `RunState.Current.SetHp(evt.RemainingHp)` |

## 实测

| 步骤 | 结果 |
| --- | --- |
| `hp 55` 后开战 | 战斗中 `PlayerHp = 55` |
| 手动制造状态（加 2 层虚弱、抽到 7 张） | — |
| 调 `OnClose`（＝状态机退出） | `m_State=null`、`CardPreviewSource.State/Target=null`、`DebugPendingLineup=null`、buff 条已销毁、旧 `BattleState` 手牌/buff/敌人全 0 |
| 再开一场 | 手牌 5、敌人 1、玩家 buff **0**（无残留）、`HP=55` 延续、buff 条数量仍为 **1** |
