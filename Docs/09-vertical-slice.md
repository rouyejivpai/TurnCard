# 09 最小可玩切片

状态：可运行。目的是验证「翻面」这一核心手感，不是完整游戏。

## 1. 怎么跑

1. 打开场景 `Assets/Scenes/Battle.unity`。
2. 点 Play。
3. 点击不需要目标的牌（技能）→ 直接使用并翻面。
4. 拖拽攻击牌到敌人身上 → 松手命中敌人即使用并翻面；卡牌**原地不动，只向上浮起**，
   箭头从卡牌上边缘以曲线指向鼠标。
5. 右键或悬停 0.8 秒在一张手牌上 → 右上角显示它翻面后的样子。
6. 点击左下抽牌堆 / 右下弃牌堆 → 打开面板查看里面的卡牌。
7. 点「结束回合」→ 手牌进弃牌堆，敌人结算攻击，进入下一回合。

## 2. 包含什么

| 层 | 内容 |
| --- | --- |
| 数据 | 10 张双面卡（共 20 个面）、1 个双形态敌人（石像鬼/裂石者） |
| 规则 | 回合制、能量 3、抽牌至 5、护甲每回合清零、手牌回合末全弃、翻面后留在手牌 |
| 敌人 | 每回合固定伤害、意图明示、血量归零当场翻面且第二形态满血、第二形态归零才死 |
| 表现 | 3D 绕轴翻转 0.35 秒、程序合成的翻转音效、敌人卡左下攻击/右下血量 |
| 交互 | 无目标点击；有目标拖拽（原地浮起 + 上凸贝塞尔箭头 + 悬停高亮）；右键/悬停查看背面 |
| 查看 | 抽牌堆与弃牌堆可点开，**全屏**以真实卡面陈列（一行 5 张）；抽牌堆打乱显示顺序 |

## 3. 已验证

- **点击出牌**：卡面翻到背面、护甲增加、能量扣除、卡牌留在手牌。
- **拖拽**：卡牌原地浮起不跟手，贝塞尔箭头从卡牌上边缘指向指针并带箭头头部。
- **箭头弧度方向**：对右上、左上、正右、正左、正上、极右倾六个方向做了数值验证，
  曲线中点均高于弦中点，即始终上凸；左右对称目标的控制点互为镜像。
- **拖拽释放**：命中敌人后扣血、卡牌翻面。
- **背面查看**：面板出现在所指卡牌的右上方，带 0.18 秒的放大回弹动画；
  效果文本会自动换行，描述若只是复述效果则隐藏。
- **牌堆查看**：点击抽牌堆打开**全屏**面板，以 250×352 的卡面陈列，一行 5 张，
  显示名称、费用、类型、当前面；卡面尺寸大于手牌，便于辨认。
- **规则逻辑**：直接调用 `BattleState` 的单元级验证——翻面交替、能量扣除、
  敌人两次归零的翻面与死亡、回合末手牌清空。

## 4. 已知问题

| 问题 | 说明 |
| --- | --- |
| 敌人攻击缺少视觉反馈 | 结算只更新数值，没有攻击动画或飘字 |
| 翻转音效是程序合成的 | 只有一声噪声，不是美术资源 |
| 卡面无美术 | 纯色块 + 文字，卡背与卡面靠颜色区分 |
| 悬停判定较粗 | 以整张卡为热区，没有做卡牌抬起时的热区偏移 |
| 超出切片范围 | 选关、奖励、商店、休整、地图都还没有 |

## 5. 自动化验证的坑

用代码合成 UI 事件（`ExecuteEvents.Execute` 派发 pointer/drag）会让 MCP 桥接掉线，
多次尝试后编辑器会话卡死。更麻烦的是：**从工具调用里触发 Canvas 重绘（拖拽起手、
箭头设点、构建面板）同样会让编辑器主线程卡死**，只能重启编辑器。

因此本版留了一个调试开关 `BattleScene.DebugOpenDrawPileOnStart`：
在播放模式中把它设为 true，游戏会在下一帧的 `Update` 里自己打开抽牌堆，
构建发生在正常的游戏循环内而不是工具调用栈里，这样就能安全截图核对版式。
默认关闭，不影响正常游玩。

## 6. 代码结构

```
Assets/Game/Scripts/
  Battle/BattleState.cs        纯逻辑：回合、能量、抽牌、翻面、敌人结算
  Battle/BattleScene.cs        场景装配与流程编排
  UI/CardView.cs               卡牌视图（预制体驱动）：翻面动画、原地上浮拖拽、右键/悬停
  UI/CardInspectService.cs     所有卡牌共用的背面查看服务
  UI/EnemyView.cs              敌人卡视图、意图、翻面动画
  UI/BezierArrow.cs            二次贝塞尔曲线箭头（自定义 Graphic 生成网格）
  UI/CardInspectPanel.cs       右上角背面信息面板
  UI/PilePanel.cs              抽牌堆 / 弃牌堆查看面板
  UI/UiFactory.cs              运行时构建 UGUI 的小工具
  Data/*.cs                    卡牌、敌人、内容索引
  Editor/DataTableImporter.cs  CSV → SO 生成器
  Editor/UiPrefabBuilder.cs       界面预制体生成器（菜单 Tools/TurnCard/生成界面预制体）
```

卡牌视觉已抽成预制体 `Assets/Game/Resources/UI/CardView.prefab`，
手牌与牌堆共用同一份、靠缩放区分尺寸，详见 `10-card-visual.md`。

`BattleState` 不依赖任何 UI，接入 GameFramework 的 Procedure/UI 时可以直接复用，
只需要替换 `BattleScene` 这一层。
