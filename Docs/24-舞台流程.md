# 24 舞台流程（同一场景内跑完整流程）

状态：**方案待确认**（本轮只落地了「选卡点不了」的修复与配置资产，未改流程结构）

## 1. 目标

所有流程表现都在**同一个场景**（现在的 Battle 场景）里完成，不再切场景、不再切整屏界面。
舞台区是一块可替换内容的区域：

```
战斗    → 敌人卡
胜利    → 宝箱（关闭态）→ 点击 → 打开态 → 0.5s → 选卡奖励（全屏浮层）
选完    → 舞台区显示 3 个「下一幕」选项（占位）
点选项  → 进入下一场战斗
```

## 2. 已确认的决定

| 项 | 决定 |
| --- | --- |
| 舞台区 | **新增 `StageArea`**，按阶段换内容；敌人卡与 `EnemyArea` 保留 |
| 宝箱素材 | 先用占位，美术随后自己放（关闭/打开两张） |
| 胜利→奖励房 | **自动**：敌人卡播完死亡动画，宝箱直接出现，等玩家点 |
| 选卡奖励 | **全屏复用 `CardGridScreen`**，选完关闭回到舞台 |
| 路线选项 | **先用 3 个占位按钮**，不接地图数据 |
| 旧 Procedure | **保留 FSM**，只改表现（不换界面） |

## 3. 关键结构问题（必须先解决）

`ProcedureBattle.OnLeave` 里会 `UIHost.Shared.Close(form)` —— **切到 ProcedureReward 时 BattleForm 就被销毁了**，
舞台区随之消失，宝箱没地方放。

所以流程必须改成「**战斗胜利后不离开 ProcedureBattle**」，由 BattleForm 自己走完
「宝箱 → 选卡 → 路线」三段，最后才切流程：

```
ProcedureBattle.OnBattleFinished(victory)
   ├─ 失败 → ChangeState<ProcedureGameOver>
   └─ 胜利 → 不离开流程！
             BattleForm.ShowChest(onOpened)
                └─ 玩家点宝箱 → 打开态 → FlowSettings.ChestOpenDelay(0.5s)
                   → 打开 CardGridScreen（全屏浮层）
                      └─ 选完 → 关闭浮层 → BattleForm.ShowRoutes()
                         └─ 玩家点选项 → BattleFinishedEvent(Next)
                            → 关闭 BattleForm → ChangeState<ProcedureMap>
```

奖励数据（金币、加牌）仍在 ProcedureReward 里做，只是它不再负责打开界面。
