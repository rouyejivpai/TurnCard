# 26 · 开幕幕布（Curtain）

战斗界面进场时拉开幕布的一次性动画。

## 素材

`Assets/Game/Art/BG/dynamic_curtain.png` —— **1920×108 的横排精灵条，10 帧**，
每帧 192×108（16:9），命名 `dynamic_curtain_0` ~ `dynamic_curtain_9`。
帧内不透明像素从 42% 逐帧降到 6%，也就是幕布从中间往两边拉开。

## 动画用的是原生 Animator

UGUI 的 `Image` 没有内置帧动画组件，Unity 的标准做法是 **Animator + AnimationClip 给 `Image.m_Sprite` 打 sprite 关键帧**，本项目采用这个方案：

| 资产 | 路径 | 说明 |
| --- | --- | --- |
| `CurtainOpen.anim` | `Assets/Game/Resources/UI/Battle/Curtain/` | 10 个 sprite 关键帧，12 fps，总长 0.83s，`loopTime = false` |
| `CurtainClose.anim` | 同上 | **同一组帧反向排列**（9→0），用作关幕，0.83s |
| `CurtainOpen.controller` | 同上 | 状态 `CurtainOpen`（默认）+ `CurtainClose` |
| `dynamic_curtain*.png` | `Assets/Game/Art/BG/` | 精灵条，10 个子 sprite |

> 为什么不直接 `Animator.speed = -1` 倒放：**Mecanim 的 `Animator.speed` 不接受负数**（会被夹成 0），
> 所以反向播放必须用一条反向的 clip，这也是 Unity 里做「倒放动画」的标准做法。

想调节奏就直接在 **Animation 窗口**里拖关键帧、改采样率，或者给 clip 加 `Animation Events`。
帧内容要换：重新生成 clip（下面「重新生成」一节），或者在 Animation 窗口里替换 sprite 引用。

## 结构

`BattleFormWindow.prefab` 根节点下的 `curtain`：

| 组件 | 配置 |
|---|---|
| `RectTransform` | 拉伸铺满 1920×1080（`sizeDelta = 0`） |
| `Image` | sprite = `dynamic_curtain_0`，Simple，`raycastTarget = false`（全屏遮挡不能吃点击） |
| `Animator` | controller = `CurtainOpen`，`Update Mode = Unscaled Time`，`Culling Mode = Always Animate` |
| `CurtainView` | 只负责「开战触发播放 + 播完退层」，不参与换帧 |

## 行为

**开一场战斗的时序**（`BattleForm.StartBattle` → `BattleIntroRoutine`）：

```
1. 清场          ResetBattleState()：手牌 / 敌人卡 / buff 条 / 结算文字 / 舞台全部清掉
2. 关幕          幕布开着才播 CurtainClose（倒放）；本来就关着就直接保持（不播，避免闪一下）
3. 停关幕帧      关幕动画播完，停在 dynamic_curtain_0
4. 初始化怪物     BuildEnemyArea()
5. 战斗初始化     Setup → StartPlayerTurn → BuildHand → RefreshHud
6. 保持在关幕帧   FlowSettings.CurtainHold（默认 0.35s）
7. 开幕          CurtainView.PlayAll()（CurtainOpen）→ 播完退到最底层
```

- **战斗结束不关幕**：`BattleEnded` 不再播任何幕布动画，宝箱 / 结算面板直接出现。
- **层次规则**：只有「开幕播完」才 `SetAsFirstSibling()`（退到最底层，剩下的边角不挡 UI）；
  **「关幕播完」必须留在最上层**——否则会被 `Background` 盖住，看起来像幕布消失了一下。
- `Awake` 里先 `CloseImmediate()`（第 0 帧、`Animator.speed = 0`、暂停、最上层），保证界面一打开就是关着的。
- 10 帧 / 12 fps ≈ 0.83 秒（开、关都是）。

## API（`CurtainView`）

| 方法 / 属性 | 说明 |
| --- | --- |
| `Play()` | 从头播开幕（自动提到最上层） |
| `PlayReverse()` | 关幕：播 `CurtainClose` 反向 clip |
| `CloseImmediate()` | 立刻摆成关幕（第 0 帧 + 暂停） |
| `CloseAnimatedAll()` | 静态：开着的播关幕，关着的保持，返回是否播了动画 |
| `Stop()` | 停在当前帧 |
| `IsPlaying` / `IsClosed` | 是否在播 / 是否处于关幕状态 |
| `CurtainView.PlayAll()` / `CloseAll()` | 静态：所有幕布一起播 / 一起关 |

## 可调参数

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `m_StateName` | `CurtainOpen` | AnimatorController 里的状态名 |
| `m_SendToBackWhenDone` | true | 播完退到最底层 |
| Animator 上的 `speed` | 1 | 播得太快/太慢直接改这个，或在 clip 里调采样率 |

## 重新生成动画资产

```csharp
// 10 个 sprite → ObjectReferenceKeyframe（1/12 秒一帧）
var binding = new EditorCurveBinding { path = "", type = typeof(Image), propertyName = "m_Sprite" };
AnimationUtility.SetObjectReferenceCurve(clip, binding, keys);
// clip 的 loopTime 要设成 false，否则播完会重头再放
```

## 注意

- 幕布和手牌**同一层 UI**，靠兄弟顺序控制遮挡；如果以后把手牌放进子 Canvas，兄弟顺序就失效，需要改成独立 Canvas + `sortingOrder`。
- 要"战斗结束时闭幕"，把 `PlayReverse()` 接到胜利流程（`BeginVictoryFlow`）即可。
