# 26 · 开幕幕布（Curtain）

战斗界面进场时拉开幕布的一次性动画。

## 素材

`Assets/Game/Art/BG/dynamic_curtain.png` —— **1920×108 的横排精灵条，10 帧**，
每帧 192×108（16:9），命名 `dynamic_curtain_0` ~ `dynamic_curtain_9`。
帧内不透明像素从 42% 逐帧降到 6%，也就是幕布从中间往两边拉开。

## 结构

`BattleFormWindow.prefab` 根节点下的 `curtain`：

| 组件 | 配置 |
|---|---|
| `RectTransform` | 拉伸铺满 1920×1080（`sizeDelta = 0`） |
| `Image` | sprite = `dynamic_curtain_0`，Simple，`raycastTarget = false`（全屏遮挡不能吃点击） |
| `CurtainView` | `m_Frames` = 10 帧按序、`m_Fps = 12`、播完停在最后一帧、播完退到最底层 |

## 行为

- `BattleForm.StartBattle()` 里调 `CurtainView.PlayAll()` → **每次开战重播**（含同一界面重开）。
- 播放时把幕布 `SetAsLastSibling()`（盖住正在登场的手牌/敌人），
  播完 `SetAsFirstSibling()`（剩下的幕布边角退到最底层，不再挡 UI）。
- 10 帧 / 12 fps ≈ 0.83 秒。

## API

| 方法 / 属性 | 说明 |
| --- | --- |
| `Play()` | 从头播（自动提到最上层） |
| `PlayReverse()` | 倒放（闭幕） |
| `Stop()` | 停在当前帧 |
| `SetFrame(int)` | 直接摆到某一帧 |
| `CurrentFrame` / `FrameCount` / `IsPlaying` | 状态读取 |
| `FrameChanged` | 每换一帧触发，参数是帧号 |
| `CurtainView.PlayAll()` | 静态：场景里所有幕布一起播 |

编辑器里改完帧序列后，右键组件菜单里的 `CollectFramesFromSprite`
（`CurtainView.CollectFramesFromSprite()`）可以按贴图自动重新收集帧。

## 可调参数

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `m_Fps` | 12 | 播放速度 |
| `m_HoldLastFrame` | true | 播完停在最后一帧；false 则隐藏 Image |
| `m_Loop` | false | 循环（调试用） |
| `m_UseUnscaledTime` | true | 不受 `timeScale` 影响（暂停时也能播完） |
| `m_SendToBackWhenDone` | true | 播完退到最底层 |

## 注意

- 幕布是**和手牌同一层**的 UI，靠兄弟顺序控制遮挡；如果以后把手牌放到子 Canvas 里，
  兄弟顺序就不再生效，需要改成独立 Canvas + `sortingOrder`。
- 如果要"战斗结束时再闭幕"，把 `PlayReverse()` 接到胜利流程（`BeginVictoryFlow`）即可。
