# 25 · 局内调试控制台

按 **`**（反引号，中文键盘上就是 **·** 键）随时开关。面板固定在左下角，`Esc` 也能关。

调试台只在运行时存在：游戏启动后由 `DebugConsole.Bootstrap` 自动挂到 `[DebugConsole]` 物体上，
自带一个 `sortingOrder = 32000` 的 Overlay Canvas，**不需要改场景、不需要预制体参与启动流程**。

- 代码：`Assets/Game/Scripts/UI/Debug/DebugConsole.cs`（输入 / 渲染）、`DebugCommands.cs`（命令分发）
- 面板预制体：`Assets/Game/Resources/UI/Debug/DebugConsolePanel.prefab`
- 重新生成预制体：菜单 `Tools/TurnCard/生成调试台预制体`，或 `DebugConsoleBuilder.Build()`

## 命令一览

| 命令 | 作用 |
|---|---|
| `battle <敌人id...>` | 直接开一场指定阵容的战斗，如 `battle 6`、`battle 8 9` |
| `battle` | 按当前池子的随机编队重开一场 |
| `addcard <卡牌id>` | 往牌组加一张；战斗中同时插到抽牌堆最上面，下一抽就能摸到 |
| `removecard <卡牌id>` | 从牌组删一张 |
| `deck` | 打印当前牌组（下标 + id + 名字） |
| `cards` | 列出所有卡牌 id 与费用 |
| `enemies` | 列出所有怪物 id / 形态 / 血量 / 池子，占位怪标 `[占位]` |
| `intents <敌人id>` | 看某只怪的招式表（正面/反面、数值、段数、buff） |
| `hp <n>` | 改玩家血量（下一场战斗生效） |
| `energy <n>` | 改当前能量（仅在战斗中有效） |
| `gold <n>` | 改金币 |
| `kill` | 秒掉所有敌人（会自动处理翻面形态，可直接验证胜利流程） |
| `clear` / `close` | 清屏 / 关闭 |
| `help` | 打印命令列表 |

`↑` / `↓` 翻命令历史，`Backspace` 删字。

## 实现要点

- **`battle` 走的是和正式流程同一条路**：`BattleForm.DebugPendingLineup` 静态字段 +
  `BattleForm.StartBattle` 里优先消费它，消费完立刻清空，所以不会污染后续正常战斗。
  界面没打开时用 `UIHost.Shared.Open<BattleForm>("UI/Battle/BattleFormWindow")` 打开；
  已打开时调 `DebugRestartWith()` 原地重开（复用正式的 `RestartBattle`，会清手牌/敌人卡）。
- **`addcard` 两个地方都加**：`RunState.Current.AddCard` 影响后续战斗，
  `BattleState.DebugAddToDrawPile` 让当前这场立刻能摸到。
- **`kill` 要打多轮**：敌人血量归零会先翻面（双形态），所以循环最多 8 次直到 `IsDead`。

## 注意

- 调试台用 `Input.GetKeyDown` / `Input.inputString`（旧 Input API），和项目现有输入方式一致。
- 打开面板时**不暂停游戏**：如果正在敌方回合协程里，命令会立刻生效，注意别在动画中途 `kill`。
- 这是开发工具，正式构建里也保留（无副作用，只为方便自测）；如果要出包，可按 `#if DEVELOPMENT_BUILD` 包一层。
