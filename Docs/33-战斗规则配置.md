# 33 · 战斗规则配置（BattleRules）

影响**结算**的参数不再写死在代码里，放在 `Resources/Config/BattleRules.asset`。

## 怎么配

Unity 里选中 `Assets/Game/Resources/Config/BattleRules.asset`：

| 字段 | 含义 | 默认 |
| --- | --- | --- |
| `Hand Size` | **额定手牌数**：每回合补到这么多张（高于它不额外抽） | 5 |
| `Max Hand Size` | 手牌上限，超过就不再抽（0 = 不限） | 10 |
| `Energy Per Turn` | 每回合能量 | 3 |
| `Player Max Hp` | 玩家最大生命 | 80 |

改完保存即可，**不用改代码**。

## 读取方式

```csharp
BattleState.HandSize        // → BattleRules.Current.HandSize
BattleState.MaxEnergy       // → BattleRules.Current.EnergyPerTurn
BattleState.PlayerMaxHp     // → BattleRules.Current.PlayerMaxHp
```

`BattleRules.Current` 第一次访问时 `Resources.Load` 并缓存；资产缺失时回落到一套默认值，
不会因为没配而崩。改完资产想立刻生效（比如在运行时调试）调 `BattleRules.ClearCache()`。

## 数值从哪来

`RunState.StartingHp`（整局起始血量）仍是整局数据，`BattleRules.PlayerMaxHp` 只作为
`BattleState` 侧的兜底上限；目前两者都是 80，改的时候要一起改。

## 抽牌规则

```
StartPlayerTurn → DrawUpTo(HandSize)
DrawCards(n)    → DrawUpTo(当前手牌 + n)
两者都会先夹到 MaxHandSize 再抽
```
