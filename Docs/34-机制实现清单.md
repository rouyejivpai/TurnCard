# 34 · 重剑卡包机制清单

记录「重剑卡包」（Cards id 18–34）各机制的实现状态与规则约定。**全部机制已实现。**

## 机制总览

| 机制 | 规则 | 涉及卡 | 实现位置 |
| --- | --- | --- | --- |
| 状态牌（Status） | 可打出、按表内费用、无事发生；回合结束按普通规则进弃牌堆 | 疲惫 / 深度疲劳 / 磨损 / ！不公！ | `CardType.Status` |
| 消耗堆 | 本场战斗内不回抽牌堆；界面「消耗 N」按钮可查看；战斗结束清空 | 撕毁、放逐、重整旗鼓 | `BattleState.ExhaustPile / ExhaustCard`、`exhaust_self` |
| 丢弃状态牌并抽等量 | 弃掉手牌所有状态牌，按弃掉张数抽牌 | 透支 | `discard_status` |
| X 费 | `params.x` 声明来源：`energy` / `status` / `hand`；费用 = 该值 | 力降十会、！不公！ | `XSource / EvaluateX / EffectiveCost` |
| `{X}` 占位 | 效果串写 `{X}`；描述写 `{x}` 显示当前值 | 力降十会、全力一击、自愈、死斗 | `CardEffects` 解析 + `x` token |
| 派生数值 | `damage_times` / `armor_times` / `flip_status` / `armor_per_status` / `losehp_per_status` | 全力一击、自愈、力降十会、佯攻、损伤 | 同名效果 |
| 临时力量 | buff 32，`attack:+1`，`decayTrigger=turnEnd`、`decayStacks=99` → 回合结束掉光 | 死斗 | `temp_strength` |
| 选牌（手牌） | 点牌 → 可选亮 / 不可选暗 + 顶部提示 + 右下 √；选中金色底光；**选完才翻面、才结算瞬发**；不可取消 | 条件反射、深吸、剑盾 | `BeginPlay / CompletePlay`、`CardEffects.Suspended` |
| 选牌（牌堆） | 直接打开对应牌堆，点一张即入手（无需二次确认） | 协议、追悔 | `CardListViewScreen.ShowCards(IList<CardInstance>, …)` |
| 计谋触发 | 只有「打出的那张牌当前面是状态牌」才触发 | 计谋：守 / 计谋：攻 | `BuffTrigger.StatusPlayed` + buff 33/34 |
| 回合末被动 | 在**弃牌之前**按手牌结算 | 佯攻（2×状态数护甲）、损伤（状态数掉血） | `EndPlayerTurn` 先跑 TurnEnd；buff 35/36 |
| 打出条件 | `params.require = status>N`；不满足不扣费、不可打出 | 围困 | `CanPlayFace` / `PlayResult.ConditionNotMet` |
| 抽到释放（关键词） | 抽到即执行该面效果，牌留在手上 | 以吾之名 | `KeywordMechanics.DrawRelease` + `RunDrawRelease` |
| 相邻状态牌判定 | 力破万法左右邻是状态牌 → 4 段；撕毁相邻状态牌改为消耗 | 力破万法、撕毁 | `damage_times_adjacent_status` / `discard_adjacent` |
| 翻面并打出 / 打出并丢弃 | 放逐把状态牌翻回正面并跑正面效果；重整旗鼓跑完效果再丢弃 | 放逐、重整旗鼓 | `ForceFlipToFrontAndPlay` / `PlayFrontThenDiscard` |

## 出牌时序（选牌架构）

```
点击卡牌 → BattleState.BeginPlay
   ├─ 校验打出条件 / 扣费 / 记录 X
   ├─ 跑效果；遇到「要选牌」→ BeginChoice + CardEffectContext.Suspended
   │    （Suspended 会中止剩余效果；此时**不翻面、不收瞬发**）
   └─ 返回 NeedsChoice
→ 表现层进选牌（m_Busy=true，其余输入全部拦住）
→ 玩家选牌 + √（或点牌堆）
→ BattleState.CompletePlay：应用选择 → RequestFlip(打出的牌) → 收瞬发
→ 表现层继续：翻面动画 → 弹道 → 瞬发
```

## 已知取舍

- `{x}` 在描述里显示"当前值"：X 费牌打完能量清零后，描述里的 `{x}` 会变成 0 —— 与卡面费用 X 一致，属预期。
- 放逐 / 重整旗鼓会连打状态牌的正面效果，为避免互相递归加了 `m_ForcedPlayDepth`（嵌套一层即停）。
- 抽到释放同样有 `m_DrawReleaseDepth` 保护，避免抽牌链路里自我递归。
- 回合结束被动改到**弃牌之前**结算（否则佯攻/损伤数不到手牌里的状态牌）。
