# 34 · 重剑卡包机制清单

记录「重剑卡包」（Cards id 18–34）各机制的实现状态与规则约定。

## 已实现

| 机制 | 规则 | 涉及卡 | 实现位置 |
| --- | --- | --- | --- |
| 状态牌（Status） | 可打出、按表内费用、无事发生；回合结束按普通规则进弃牌堆 | 疲惫 / 深度疲劳 / 磨损 / ！不公！ | `CardType.Status`、`CardType.Status` 判定 |
| 消耗堆 | 本场战斗内不回抽牌堆；界面右下「消耗 N」按钮可查看；战斗结束清空 | 撕毁、放逐、重整旗鼓 | `BattleState.ExhaustPile / ExhaustCard`、`exhaust_self` |
| 丢弃状态牌并抽等量 | 弃掉手牌所有状态牌，按弃掉张数抽牌 | 透支 | `discard_status` |
| X 费 | `params.x` 声明来源：`energy`（全部能量）/ `status`（手牌状态牌数）/ `hand`（手牌数）；费用 = 该值 | 力降十会（energy）、！不公！（status） | `BattleState.XSource / EvaluateX / EffectiveCost` |
| `{X}` 占位 | 效果串里写 `{X}`，执行时替换成当前 X；描述里写 `{x}`，显示当前值 | 力降十会、全力一击、自愈、死斗 | `CardEffects` 解析、`CollectPreviewTokens` 的 `x` token |
| 派生数值 | `damage_times:值,次数`、`armor_times:值,次数`、`flip_status:张数` | 全力一击（4×手牌）、自愈（5×状态数）、力降十会（翻状态牌+5×能量甲） | 同名效果 |
| 临时力量 | buff 32「临时力量」，`attack:+1`，`decayTrigger=turnEnd`、`decayStacks=99` → 回合结束掉光 | 死斗 | `temp_strength` 效果 + buff 表 |
| 选牌（手牌） | 点牌 → 进入选牌：可选亮 / 不可选暗、顶部提示、右下 √；选中后金色底光。**选完才翻面、才结算瞬发** | 条件反射、深吸、剑盾 | `BeginPlay / CompletePlay`、`CardEffects.Suspended` |
| 选牌（牌堆） | 直接打开对应牌堆，点一张即置入手牌（不需要二次确认） | 协议、追悔 | `CardListViewScreen.ShowCards(IList<CardInstance>, …)` |

## 出牌时序（选牌架构）

```
点击卡牌 → BattleState.BeginPlay
   ├─ 校验 / 扣费 / 记录 X
   ├─ 跑效果；遇到「要选牌」→ BeginChoice + CardEffectContext.Suspended
   │    （Suspended 会中止剩余效果；此时**不翻面、不收瞬发**）
   └─ 返回 NeedsChoice
→ 表现层进选牌（m_Busy=true，其余输入全部拦住）
→ 玩家选牌 + √（或点牌堆）
→ BattleState.CompletePlay：应用选择 → RequestFlip(打出的牌) → 收瞬发
→ 表现层继续：翻面动画 → 弹道 → 瞬发
```

这就是「选牌流程结束前不执行其他卡牌效果」的实现保证。

## 冲突提醒

`{x}` 在描述里只显示"当前值"，X 费牌在打出**前**显示的就是当前能量；
打完能量清零后，描述里的 `{x}` 会变成 0 —— 这是预期行为（和卡面费用 X 一致）。
